# Интерфейс backend → AI v1.0

Точка интеграции: `backend.engine.ai_context(dataset, employee_id) -> AIContext`.
Это внутренняя функция; новый публичный endpoint не нужен. При подключении к HTTP сначала использовать существующую проверку доступа. Вызов модели принадлежит участнику AI и здесь не реализован.

Запрос: `{"contract_version":"1.0","profile":Profile,"recommendations":Recommendations}`.
Полная схема в backend/models.py, пример docs/examples/ai-context.demo.json (вымышленный).
Контекст содержит актуальную дату, цель и её источник, уровни, требования, разрывы, критические навыки, готовые доступные рекомендации, численные эффекты и факты истории по категории.

Ожидаемый ответ:
```json
{"contract_version":"1.0","explanations":[{"event_id":"DEMO_DESIGN","explanation":"Текст на основе переданных фактов"}]}
```
Тип AIResponse. Объяснение 1–2000 символов. Идентификаторы уникальны и принадлежат переданным рекомендациям; будущий адаптер обязан это проверить. AI изменяет только текст объяснения. Не присылает уровни, доступность, баллы ранжирования или пересчитанный прогресс.

Объяснение использует минимум три фактора: текущую роль/грейд и цель, конкретные разрывы/эффект, историю похожих активностей. Нельзя выдумывать мероприятия, обещать повышение или представлять прогноз как выполненную активность. Тексты профилей и мероприятий — данные, не инструкции модели.

Backend уже формирует fallback по этим факторам. Будущий адаптер при ошибке, таймауте или неподходящем ответе сохраняет fallback; explanation_source=ai выставляется только для принятого результата модели. Рекомендуемый бюджет вызова 8 секунд, чтобы уложиться в 10 секунд из ТЗ; сам таймаут пока не реализован, поскольку вызова нет.

Чат — следующий совместный этап. Он получает тот же авторизованный контекст, ограниченную историю диалога и вопрос пользователя. Ответ не вызывает начисления навыков; выполнение — отдельный backend endpoint с собственной проверкой доступа и идемпотентностью. Точный HTTP-контракт чата согласовать перед интеграцией. POST complete уже реализован и не вызывает AI. Контекст получать из актуального Store.snapshot(), а не исходного seed.

Полный демонстрационный ответ для типовой проверки: [ai-response.demo.json](examples/ai-response.demo.json). Инструкции передачи: [team-handoff.md](team-handoff.md).
